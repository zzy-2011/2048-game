# 🧩 2048 · 数字合并

经典 2048 益智小游戏，纯 HTML/CSS/JS 实现，**无任何外部图片或依赖**。

## 玩法
- **方向键 / WASD** 移动方块，**手机直接滑动**屏幕
- 相同数字相撞合并成它们的和，每次移动后随机出现一个新方块（2 或 4）
- 目标：合成 **2048**！合成后可以选择继续挑战更大数字
- 当棋盘填满且无可合并的相邻方块时，游戏结束

## 特性
- 4×4 网格，经典配色与出现/合并动画
- 键盘 + 触屏滑动双操作
- 实时分数 + 最高分（保存在浏览器 `localStorage`）
- 胜利 / 失败覆盖层，可「继续玩」或「再来一局」

## 运行
直接用浏览器打开 `index.html` 即可，或启动本地静态服务器：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```
